# برنامه‌ریزی و کنترل فروش توسن تکنو — PWA

## انتشار
این مخزن برای انتشار مستقیم با GitHub Pages آماده شده است. در تنظیمات مخزن، از مسیر **Settings → Pages** گزینه **Deploy from a branch** را انتخاب کنید، سپس Branch را روی **main** و Folder را روی **/(root)** بگذارید و Save کنید.

## نصب روی iPhone
آدرس HTTPS سایت را در Safari باز کنید، Share را بزنید و **Add to Home Screen** را انتخاب کنید.

## نصب روی Android
در Chrome سایت را باز کنید و از منوی مرورگر گزینه **Install app** یا **Add to Home screen** را بزنید.

## داده‌ها و حریم خصوصی
نسخه فعلی داده‌های قابل ویرایش را در حافظه محلی مرورگر (localStorage) نگه می‌دارد. همگام‌سازی بین دستگاه‌ها یا کاربران فعال نیست. اتصال PostHog نیز در این نسخه پیکربندی نشده است.
